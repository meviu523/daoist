## 浏览器 22 组检查

## HTTP、AI 与范围限制

Node 测试在本机实际启动 HTTP 服务，检查页面、engine/clock/progression 静态模块、MIME、CSP、健康检查、静态白名单、Host/Origin 限制、请求与响应大小、方法和限流。上游模型为模拟 fetch，不使用付费接口。

本环境浏览器导航受限制，采用 `set_content` 渲染真实构建页面，并显式模拟 localStorage 和 AI fetch。页面隐藏由测试分发可见性事件，不等于真实操作系统冻结。没有修改浏览器策略，也不把模拟结果称为真实浏览器落盘或真实手机验证。

未验证真实付费模型兼容性、Safari/Firefox、物理 iOS/Android、系统级省电冻结、浏览器磁盘配额耗尽或高并发多标签写入、未知原仓库存档。线上部署状态以对应 GitHub Pages 工作流为准，不由本地测试推断。
