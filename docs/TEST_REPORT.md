## 新增规则与存档回归

`tests/realtime.test.mjs` 新增 41 项，覆盖空闲连续计时、无效时间增量、启动不跳时、不瞬移或提前扣全程资源、道路中途坐标、离开地点后服务限制、中途重新寻路和非桥过江拒绝。

覆盖停车仍计订单时限、恢复订单不重复扣灵力、超时降奖、只允许一个主要行动、即时事务不推进时间或重抽订单。休息、睡眠、充电、修炼逐步结算，夜间收益按实际时段分段；炼丹/突破取消不退投入；救助沿路转运后治疗，不瞬移。

跨日用例包括空闲扣租、睡眠中租金不足立即结束、配送与搬家恰在零点完成时房租优先、存档往返不重扣。订单补空缺、过期、空列表读档不重抽；待选剧情冻结时间，耗时选择往返只扣一次成本。

v4 的人物、住处、交通升级和模式迁移到 v5；多次途中保存保留小数时间、坐标、消耗和路线。损坏的路段、目的地、行动类型拒绝载入，不静默瞬移；新键空列表不从旧键复活已删除记录。

比较不同时间切片下的距离、资源、种子、天气与订单；覆盖低车况降速、耐久耗尽途中停车。时钟单测覆盖独立暂停原因、倍率一致、恢复不补算以及长帧自动暂停。

既有测试迁移为通过 `G.advance` 真正完成活动，不保留测试专用瞬间结算路径。40 单自动游玩、主要结局可达性、NPC 发现制、AI 白名单和旧存档异常场景继续验证；这不是完整经济平衡或无缺陷证明。

## 浏览器 18 组检查

完整清单在 `docs/test-results/continuous-browser.json`。核心断言如下：

- 空闲时钟推进；接单先建立活动、沿路移动，到达/选择前不发配送奖励；时间、坐标和资源一起暂停。
- 普通移动帧保留同一人物 DOM 节点；途中保存恢复相同路程、订单和小数位置，载入默认暂停。
- 移动中签到/兑换保持系统面板打开且不推进活动；关闭面板不会解除手动暂停。停止配送不停止时间，继续后只交付一次。
- 原先运行的面板关闭后继续，1/3/10 倍率正确；模拟 visibilitychange 后冻结，返回不补算；多存档隔离及冲突页面无法继续推进。
- 320/390 像素导航、时间控制、行动栏和面板不溢出，双指缩放不误接订单。
- 模拟 AI 成功、失败回退和迟到结果取消；等待与阅读冻结时间，模式不被更改。
- 另有不替换 GameClock 的真实 requestAnimationFrame 探针，实际等待验证空闲计时、移动和暂停。

脚本实际点击页面并检查状态，保存桌面、移动中、事件、手机地图和系统面板截图。大多数长活动测试仅控制 `GameClock.frame` 的输入时间戳；浏览器原生渲染循环、DOM 和交互仍真实运行。

## HTTP、AI 与范围限制

Node 测试在本机实际启动 HTTP 服务，检查页面、engine/clock/progression 静态模块、MIME、CSP、健康检查、静态白名单、Host/Origin 限制、请求与响应大小、方法和限流。上游模型为模拟 fetch，不使用付费接口。

本环境浏览器导航受限制，采用 `set_content` 渲染真实构建页面，并显式模拟 localStorage 和 AI fetch。页面隐藏由测试分发可见性事件，不等于真实操作系统冻结。没有修改浏览器策略，也不把模拟结果称为真实浏览器落盘或真实手机验证。

未验证真实付费模型兼容性、Safari/Firefox、物理 iOS/Android、系统级省电冻结、浏览器磁盘配额耗尽或高并发多标签写入、未知原仓库存档。线上部署状态以对应 GitHub Pages 工作流为准，不由本地测试推断。

## 修复的回归问题

修复浮点累计造成测试精确比较失败，改为对允许小数的游戏量使用明确误差界限；防止时间边界舍入导致提前完成活动。修复移动途中签到/兑换会意外关闭面板的问题，并将该路径纳入浏览器断言。新增 clock 模块时一并修复本机静态白名单缺失 progression 模块的问题。

## 复验

```sh
npm run check
npm test
npm run build
python tests/browser-smoke.py
```

最后一步需要安装 Python Playwright 和 Chromium；默认 `/usr/bin/chromium`，可设置 `CHROMIUM_PATH`。测试依赖不进入游戏运行依赖。
