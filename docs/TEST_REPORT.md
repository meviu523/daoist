## 规则与存档重点

测试覆盖开局姓名和模式、独立种子、道路可达/对称及跨桥路线、距离换算、速度升级与天气、足够/不足/零电量、零车况、步行、行动失败不产生部分扣费、位置移动和回合刷新。

配送包含订单时限、特殊要求、事件延迟结算、事件选择成本校验、旧订单/旧事件不重复领奖、超时降奖、待选状态保存与恢复。系统覆盖兑换不耗时/不移动、独占物品去重、每日与主线奖励条件；修行覆盖夜间收益、突破、炼丹及资源上下限。

人物包含拜访、章节条件、显式友情/情感路线以及每个关键章节至少有一个资源耗尽时仍可选的分支。连续自动游玩在750次行动预算内实际送达40单、推进到至少金丹并达成守城结局，用来排查关键循环死局；不是长周期经济平衡证明。

存档测试覆盖v3往返、可识别旧格式补齐、拒绝未来/未知格式、数值范围和白名单、原型字段防污染、多存档隔离、导入新ID、上限拒绝、混合坏档批次原子性、超大/无效JSON拒绝、自动备份恢复、写入失败仍保留可导出的内存状态，以及返回菜单不丢失未保存进度。

## 本机HTTP与AI接口重点

测试会在本机实际启动 Node HTTP server，并通过真实 HTTP 请求验证启动页、JS文件、MIME、CSP、健康检查、静态白名单（.env和服务端源码不可读）、Host与跨来源限制、方法/类型校验、请求/响应大小限制、限流。

上游模型使用模拟 fetch 响应。验证正常生成、权限外效果拒绝、非人物事件剔除关系效果、错误回退与密钥不回传。未提供真实密钥，不发送付费模型调用。

## 浏览器11项检查

1. 桌面开局、顶部玩家姓名、动态地图标记。
2. 地图接单、移动、三选项事件和延后结算。
3. 远程系统签到、即时兑换且不耗时。
4. 两份独立存档与开始页重新载入。
5. 夜间修炼界面、按钮缩放与鼠标平移。
6. 桌面流程无 JavaScript 运行时异常。
7. 390px手机布局、导航、可滚动系统面板与默认可读缩放。
8. 双指缩放不误触任务标记。
9. 手机流程无 JavaScript 运行时异常。
10. AI模式接收有界事件（模拟接口）。
11. 选择经典选项后，迟到AI回包不覆盖状态。

这些检查由脚本实际操作DOM、鼠标/触控输入并断言结果，不是只检查HTML字符串。对桌面起始页、地图、事件面板、移动端地图与系统面板进行了截图查看。

## 环境限制与未验证范围

本环境 Chromium 的管理策略阻止URL导航。未修改或绕过该策略；浏览器测试以 `set_content` 加载真实 `dist/index.html`，使用明确的内存 localStorage 与 AI fetch 模拟。

因此，浏览器检查**不是**真实 `http://localhost` 或 `file:` 来源下的完整端到端持久化验证。真实HTTP路由单独由 Node 测试覆盖，存档序列化与异常路径由规则测试覆盖；不能把两者相加说成真实浏览器落盘已验证。

尚未验证：真实付费AI/本地模型提供方兼容性，Safari和Firefox，真实iOS/Android设备，系统省电/后台冻结对交互的影响，真实浏览器存储满额与多标签高并发，未知原仓库存档、公网部署与渗透测试。

脚本中的“夜间修行”截图使用有意注入的QA状态（夜间、一定修为和货币），并非宣称从新存档一路人工玩到该状态。主地图、新建页、配送、系统等截图来自实际交互流程。

## 本机复验

```sh
npm run check
npm test
npm run build
```

浏览器脚本另外需要已安装的 Python Playwright 和可启动的 Chromium。默认使用 `/usr/bin/chromium`，可通过环境变量 `CHROMIUM_PATH` 指定自己的浏览器；找不到指定文件时会使用 Playwright默认浏览器。

```sh
python tests/browser-smoke.py
```

脚本输出放在 `artifacts/`，这个目录被Git忽略。交付的 `docs/test-results/` 是这一次执行的快照，重新测试后不会自行改写交付快照。
