# 恢复范围与差异说明

日期：2026-09-18；代码版本：1.0.0。

## 依据与可恢复性

可用依据是本项目中的历史需求摘要及当前用户“依据项目记忆复刻”的请求。尝试通过已连接 GitHub 读取旧账号仓库，接口返回账号暂停的 403 错误。没有读到旧仓库文件、分支、提交、Issue、PR 或部署产物。

因此，交付目标是**保持最后确认的产品决策，重建可运行的核心玩法**。不声称原源文件、原界面像素、原剧情原文、原平衡参数或旧存档格式已恢复。

## 需求与实现映射

| 需求 | 实现入口 | 状态及边界 |
| --- | --- | --- |
| 白天送外卖、夜里修仙 | `data.js`, `engine.js` | 可玩；不强制昼夜锁定，夜间修炼更有效率，夜间也有配送。 |
| 游戏时间流逝 | `passTime`, `travelPlan` | 行动推进，现实时间不空转；行动可跨日，触发天气、每日进度重置和周租。 |
| 所有出行按距离计时 | `route`, `travelPlan`, `move` | 沿路网寻路，不能直线穿江；天气、交通方式、车况和升级参与速度计算。 |
| 取餐配送合并 | `perform('deliver')` | 直接地图确认配送，没有独立取餐地点、取餐按钮或必须去的驿站。 |
| 任务点动态刷新 | `refreshOrders`, `CityMap.render` | 世界行动后刷新；7 个服务地点常驻，其余只有活跃任务才显示。 |
| 玩家位置显示 | `position`, `.player-marker` | 配送/旅行后地点改变，地图标记更新，并保留上一行程轨迹。 |
| 电动车没电禁行 | `travelBlock` | 零电、所需电量不足或零车况时，在移动前拒绝骑行。 |
| 电动车直接充电 | `perform('charge')`, 座驾面板 | 任意地点可直接充电，固定收费并推进30分钟；维修、升级仍要求在修车铺。 |
| 电动车继续保留 | `vehicle`, `transport` | 保留；步行是备用交通方式，不替换整个电动车玩法。 |
| 升级速度/电池/耐用 | `perform('upgrade')` | 三条独立升级，每类最高 5 级；已存档。 |
| 修仙系统和兑换币 | `ITEMS`, system 面板 | 12 项可兑换内容，丹药、材料、心法、装备；成功配送后奖励外卖币。 |
| 兑换无需到驿站、不耗时 | `perform('buy')` | 在任意当前位置即时兑换；位置、游戏分钟数不变。 |
| 多选项配送事件 | `EVENTS`, `pending`, `choose` | 模板三选一，有时间和资源影响；事件处理完才结算送达。 |
| NPC、友情和情感线 | `NPCS`, `perform('visit')` | 4 人、每人4章；拜访与日常交流，好感和信任影响分支。情感线需要明确选择。 |
| 多结局 | `endingOptions`, `ENDINGS` | 5 条条件结局，均可继续游玩。 |
| AI/非AI都能玩 | `mode`, `/api/story` | 开局固定模式；AI生成有限事件，关键剧情固定；失效降级经典，不改模式。 |
| 多存档、自动保存 | `storage.js`, `persist` | 最多12份，每次成功行动与事件状态变动保存，导出/导入建立副本。 |
| 旧版兼容/存档升级 | `sanitizeSave` | 有重建格式 v1/v2/v3 字段补齐，但无法确认未知原版存档结构。 |
| 游戏顶部改玩家名 | `renderHeader` | 已实现；开局取名，支持中文。 |
| 简洁地图布局 | `styles.css`, `app.js` | 中央地图、顶栏、左下导航；长解释在帮助；不显示装饰性英文小标题。视觉不是原版像素复现。 |
| 右下日志唯一 | `renderLogs` | 唯一结果日志区域，最多保留180条；错误提示不是另一套行为日志。 |
| 地图缩放手势 | `map.js` | 滚轮、按钮、单指拖动、双指缩放、键盘；手机默认定位玩家，可切全图。 |

## 新增而非找回的设计

青岚城/青藤小屋/听雨观等地名，林晚、陈默、沈青禾、陆听雨等人物，以及具体章节、事件和结局文字，为此次重新创作。没有复制既有小说章节。

为了使可见需求能形成可玩的闭环，补入初始资源、六境界数值、道路网格、天气倍率、破境成功率、签到/委托、每周租金、昏迷救助、免费歇息、消耗品、炼丹配方、主线里程碑和资源不足时仍可选择的事件分支。它们不是旧版设计事实。

UI 采用原生 SVG/CSS 和系统字体，没有旧仓库资产，也没有外部地图、人物肖像或字体文件依赖。

## 尚未恢复或验证的部分

旧账号、旧仓库权限、Git 提交/分支/标签/PR 历史、旧线上地址、旧环境变量与密钥、旧未导出的浏览器存档都没有恢复。

真实 AI 提供方尚未联调；公网部署、安全审计、物理移动设备兼容性和长周期平衡尚未验证。当前仅提供本机服务，带 API 密钥的公网发布需要认证、TLS、配额和日志隐私等额外设计。

没有原始截图，不能承诺原界面一致；没有旧代码，不能承诺函数名、目录或框架一致；没有旧存档样本，不能承诺直接读档。

## 补救与继续维护

所有源码、内容、构建脚本与测试都在这个包中，不依赖原 GitHub 账户。`dist/index.html` 是随包交付的独立经典版。`PROJECT_MEMORY.md` 记录用户决策与新增设计边界，下一次维护应先阅读。

后续若取得旧存档，应先保留原始副本，再根据实际字段写显式迁移；不能把“忽略未知字段”当成已恢复原存档。
